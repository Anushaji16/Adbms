create a trigger to handle inserts to the product relation (if price<5 then set price to 10)

MYSQL> CREATE TRIGGER CUST_TRIG AFTER insert ON product FOR EACH ROW BEGIN if new.price <5 then set.price=10 
end if; END$$

mysql>CREATE TRIGGER CUST_TRIG
BEFORE INSERT ON product
FOR EACH ROW
BEGIN
    IF NEW.price < 5 THEN
        SET NEW.price = 10;
    END IF;
END
